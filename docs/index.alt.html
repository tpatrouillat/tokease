How it works

Three steps, under a minute

  1. 1

    Log in to Claude Code

    Run claude login once. Your OAuth token lands in the macOS Keychain — Tokease reuses it.

  2. 2

    Install Tokease

    One Homebrew command, or clone the repo and run install.sh. No keys, no config files.

  3. 3

    Read the rings

    Three rings appear in your menu bar and fill as you use each limit. Click for details; set alert thresholds in Settings.

Privacy & trust

It runs on your Mac, and you can check

No server to trust, because there isn't one. The whole thing is a file you can read.

  • Your token stays local

    The OAuth token is read from the Keychain, used for a single GET to api.anthropic.com/api/oauth/usage, then cleared from memory. HTTP redirects are blocked so the Bearer token can't leak to another domain.

  • No telemetry, no account

    No analytics, no phone-home, no sign-up. The only network request is the one that fetches your own usage.

  • Audit it in one sitting

    Roughly 750 lines of Python plus the rumps menu bar library. Read tracker.py before you install — that's the point.

  • Honest about the caveat

    The usage endpoint is undocumented — the same one the Claude Code CLI uses. Anthropic could change it anytime; if they do, you'll see a clear error state, not a crash. Independent project, not affiliated with Anthropic.

Install

Two ways in

Both free. Requires macOS and Claude Code logged in (claude login).

Homebrew Recommended

One command. Self-contained — no Apple Developer warnings.

$ brew install tpatrouillat/tap/tokease

Then run tokease, or brew services start tokease to launch at login.

From source

Read every line first, then build. About 30 seconds.

$ git clone https://github.com/tpatrouillat/tokease.git
$ cd tokease
$ bash install.sh

FAQ

Questions, answered plainly

Is Tokease free?

Yes — free forever, MIT licensed. There's no paid tier, no account, and no upsell.

Do I need Claude Pro or Max?

Yes. Tokease reads the usage tied to a Claude Pro or Max subscription. It doesn't work with pay-as-you-go API keys.

How does it read my usage?

It reuses the OAuth token Claude Code already stored in your macOS Keychain and makes a single GET request to the same /api/oauth/usage endpoint the Claude Code CLI uses. No log parsing, no extra login.

Is my token safe?

The token never leaves your Mac except in that one request to api.anthropic.com. It's read from the Keychain, used once, then cleared from memory. HTTP redirects are blocked so the Bearer token can't leak to another domain. No telemetry, no analytics.

How is this different from ccusage or CodexBar?

ccusage estimates usage by parsing your local Claude Code logs. CodexBar is a multi-provider menu bar tool.

Tokease does one thing: read the official OAuth usage endpoint and show your real Pro/Max limits as three rings. Smaller scope, fewer moving parts.

Can I read the source?

Yes. The whole app is roughly 750 lines of Python plus the rumps library. tracker.py is the single file that does the work.

Does it use an official API?

No. The /api/oauth/usage endpoint is undocumented — it's what the Claude Code CLI itself uses. Anthropic could change or remove it anytime. If that happens, the menu bar shows an error state instead of crashing, and a fix ships once the community surfaces it.

Is Tokease affiliated with Anthropic?

No. It's an independent project, not affiliated with, endorsed by, or sponsored by Anthropic.
