Features

Everything you need, nothing you don't

Built to do one thing really well.

Real-time limits

5-hour session, weekly cap, Sonnet limit, and paid overage spend — visible in your menu bar without opening anything.

Zero config

Reads your existing Claude Code OAuth token from the macOS Keychain. No API keys, no setup files, no extra accounts.

Lightweight

Single Python file. One dependency. Minimal CPU and memory. Runs quietly in the background and auto-starts at login.

Setup

Up and running in under a minute

Three steps. No account needed.

1

Log in to Claude Code

Run claude login in your terminal. This stores your OAuth token in the macOS Keychain.

2

Install the tracker

One line: brew install tpatrouillat/tap/claude-usage-tracker. Or clone the repo and run bash install.sh.

3

See your usage

The tracker appears in your menu bar showing your current usage percentage. Click for the full breakdown.

Install

Pick your path

Both options are free. Requires macOS and Claude Code logged in (claude login).

Homebrew Recommended

One command. Installs a self-contained Python environment — no Apple Developer warnings.

$ brew install tpatrouillat/tap/claude-usage-tracker
Then run claude-usage-tracker, or brew services start claude-usage-tracker to auto-launch at login.

Build from source

Audit every line. Clone, install, run — takes about 30 seconds.

$ git clone https://github.com/tpatrouillat/claude-usage-tracker.git
$ cd claude-usage-tracker
$ bash install.sh
Transparency

How this works under the hood

No magic. Here's exactly what the app does — and the one caveat you should know about.

The endpoint is undocumented

The tracker calls api.anthropic.com/api/oauth/usage — the same endpoint the Claude Code CLI itself uses to render its usage screen. Anthropic has not published this endpoint, so it could change shape or disappear without notice.

What that means in practice: if Anthropic changes it, the menu bar will show a clear error state rather than a crash. We will ship a fix as fast as the community surfaces it. If you want to be notified when (or if) Anthropic releases an official usage API, drop your email below.

Privacy & Security

Your token never leaves your Mac

No accounts, no telemetry, no server you have to trust.

No data collection

The app runs 100% locally. No analytics, no telemetry, no phone home. Ever.

Safe token handling

OAuth token is read from the Keychain, used for one API call, then cleared from memory. HTTP redirects are blocked so the Bearer token can't leak to another domain.

Audit it yourself

The entire app is a single Python file — read it on GitHub. 74 tests cover every code path.

One email when something changes — either Anthropic releases a documented usage endpoint, or the current one breaks and the app needs an update. No newsletter, no marketing.
