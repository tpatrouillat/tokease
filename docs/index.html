A tiny macOS menu bar app that shows your 5-hour, weekly, and Sonnet usage in real time. Zero config, open source.

Features

Everything you need, nothing you don't

Built to do one thing really well.

Real-time tracking

See your 5-hour session, weekly, and Sonnet limits plus paid overage spend — all from the menu bar.

Zero config

Reads your existing Claude Code OAuth token from the macOS Keychain. No API keys, no setup files.

Lightweight

Single Python file, one dependency. Minimal CPU and memory. Runs quietly in the background.

Setup

Up and running in under a minute

Three steps. No account needed.

1

Log in to Claude Code

Run claude login in your terminal. This stores your OAuth token in the macOS Keychain.

2

Install the tracker

Clone the repo and run bash install.sh. It sets up a virtualenv and optionally auto-starts at login.

3

See your usage

The tracker appears in your menu bar showing your current usage percentage. Click to see the full breakdown.

Install

One command to get started

Requires macOS, Python 3.10+, and Claude Code logged in.

Quick install

Clone, install dependencies, and launch:

$ git clone https://github.com/tpatrouillat/claude-usage-tracker.git
$ cd claude-usage-tracker
$ bash install.sh
Privacy & Security

Your data stays on your machine

No accounts, no telemetry, no data leaves your Mac.

No data collection

The app runs 100% locally. No analytics, no telemetry, no phone home. Ever.

Safe token handling

Your OAuth token is read from the Keychain, used for one API call, then immediately cleared. HTTP redirects are blocked.

Open source

Audit every line. The entire app is a single Python file — read it on GitHub.
